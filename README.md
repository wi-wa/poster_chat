# Annulus Poster Site

Static GitHub Pages site with a five-button menu opening Chat, Contingent Knowledge Eval, Benchmarks, Handlabeled Viewer, and Data Viewer SFT. The eval model selector generates downloadable PNG comparisons in the browser. Chat uses the public API endpoint in `site.json`; the data views work independently of the inference server. `data.html` redirects to the SFT viewer so existing links and QR codes still work.

Run `python3 scripts/export_data.py --source ../mwdf --eval-only` to refresh contingent knowledge and GSM8K without changing the other snapshots. Both datasets have selectable model comparisons, sampled responses, reasoning, and scoring explanations. The current export covers 100 contingent-knowledge questions and 128 GSM8K test questions, with 3 responses per question for each of five checkpoints. Knowledge is LLM-judged; GSM8K uses normalized numeric exact match on the visible final answer.

Omit `--eval-only` to also refresh the training-data snapshots. The exporter validates the saved manifests, question-bank hashes, per-model summaries, and comparisons before publishing evaluation data. It samples 100 synthetic conversations deterministically and copies the hand-label data and full-corpus normalization statistics. `src/viewer` reuses the source viewer's calculations; only its corpus URL and presentation are adapted for the public snapshot. No private chat conversations are exported.

Local preview: `python3 -m http.server 8770 --bind 127.0.0.1`, then open `http://127.0.0.1:8770/`.

On birget, `bash scripts/start_chat.sh` starts the `chat_gradio` tmux session if it is missing: the poster launcher (`scripts/serve.py`) serves port 8770 and proxies the chat API through Gradio. The inference server sleeps until someone presses WAKE UP on the chat page. `serve.py` then runs `scripts/start_inference.sh` on the lowest-numbered GPU with 72 GB free, in tmux session `chat_inference_server`, and the page shows its startup log (`.gradio/inference_server.log`) until it answers, about 5 minutes. It serves the three 7B DPO iteration-1 checkpoints (API models `annulus-7b-exp-dpo`, `annulus-7b-reif-dpo`, `annulus-7b-control-dpo`; the chat page picks one) on port 8400. It goes back to sleep after 15 minutes without chat completions through the proxy (`serve.py --idle-sleep-minutes`, 0 disables; requests straight to port 8400 do not count). Start it by hand with `scripts/start_inference.sh [GPU]`; put it to sleep with `tmux kill-session -t chat_inference_server`. `GET /power` reports asleep, starting or awake and `POST /power/wake` wakes it. Its environment is `/data/students/wiwal2741/venvs/chat-gradio` (Gradio 6.26.0). Keep the ignored `.gradio/share-token` private: it reuses the existing tunnel identity. Confirm the printed Gradio URL matches `site.json` after restarting; share links are temporary. These sessions survive terminal disconnects, not host reboots.

Checks: `python3 -m unittest discover -s scripts -p 'test_*.py'`; with Playwright installed and the preview running, `node scripts/test_site.cjs`. The browser checks mock inference and write screenshots to `/tmp/poster-chat-screenshots`. Optional environment variables: `SITE_URL`, `CHROMIUM_PATH`, `SCREENSHOTS`.
